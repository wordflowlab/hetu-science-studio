# 产品需求

## 背景与推导

科普写作需要同时管理叙述和可检查的量化关系。数字正确不代表结论成立，类比顺畅也不代表两种机制等同。模型每轮重新估算容易引入单位和舍入错误；工程执行确定性有理数计算并保存主张依据，作者与Agent讨论解释与表达。

生成成本和等待时间会变化，但固定作品、历史依据、具体意见与连续审阅仍需长期积累。固定工程避免让模型每轮重建结构；结构化数据与多种阅读方式共用同一专业成果。插件按需安装，让作者提出目标、Agent操作工程、作者在适合的工作面阅读和选择。

## 定义与首版

科普写作是河图洛书JS／TS专业插件。把资料、带单位的数值、计算、主张、类比边界和科普文章联系起来。用户包括独立作者、编辑与外部Agent。默认旅程：读取固定资料 → 明确数值与单位 → 精确计算并核对量纲 → 主张与类比边界 → 组织文章 → 意见返工与过期复核 → 文章和计算本。

首版包含完整专业维护、准确来源回读、并行方案、固定意见、专业状态和改稿影响、上下文、固定交接、JSON／Markdown／HTML工程及专业阅读本。功能必须经机器入口执行，作者可以自然语言提出目标，也保留人工优化入口。

## 边界

研究台拥有资料研究过程，纪实拥有文章事实核实，本包拥有定量解释、计算依赖与类比边界。不是科学仿真、科研认证、医疗或工程决策系统，不复制通用计算器或抓取服务。正文、正式设定、素材、采纳与定稿由宿主和作者掌握，不另建数据库、模型渠道或内部Agent。

成功以真实创作、审阅、返工及下一轮接续为准，安装、动作数或文件存在都不足以代表完成。开发与验收状态只由08维护。
