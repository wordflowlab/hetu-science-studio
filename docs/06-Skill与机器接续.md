# Skill与机器接续

包内hetu-science-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定资料 → 明确数值与单位 → 精确计算并核对量纲 → 主张与类比边界 → 组织文章 → 意见返工与过期复核 → 文章和计算本。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

引文只追加并核验UTF-8字节。有限单位表按SI量纲和精确有理数运算，不使用浮点近似冒充精确结果；加减要求同量纲，除零、未知单位及计算依赖循环拒绝。主张固定证据、所用数量及计算组合摘要，类比说明对应关系与失效边界。文章段落固定主张及内容，依据变化后旧主张、段落与意见待复核。计算正确不认证科学结论、教学效果或现实安全。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
