# 科普写作

先发现当前已启用包、真实Schema和同包方法，携带确切WorkRef、management_ref及活动包／能力摘要。先读取固定作品、已有工程、来源、成果和意见，不重复创建或要求作者手填。

读取固定资料 → 明确数值与单位 → 精确计算并核对量纲 → 主张与类比边界 → 组织文章 → 意见返工与过期复核 → 文章和计算本。

引文只追加并核验UTF-8字节。有限单位表按SI量纲和精确有理数运算，不使用浮点近似冒充精确结果；加减要求同量纲，除零、未知单位及计算依赖循环拒绝。主张固定证据、所用数量及计算组合摘要，类比说明对应关系与失效边界。文章段落固定主张及内容，依据变化后旧主张、段落与意见待复核。计算正确不认证科学结论、教学效果或现实安全。

研究台拥有资料研究过程，纪实拥有文章事实核实，本包拥有定量解释、计算依赖与类比边界。不是科学仿真、科研认证、医疗或工程决策系统，不复制通用计算器或抓取服务。

[流程与反例](references/workflows.md)提供专业方法；[操作地图](references/operations.md)从正式清单生成。每阶段保存后回读固定修订；未知先get_operation，CAS保留原输入。用create_handoff接续下一阶段，正文采纳、定稿、外发与费用分别按确切作者决定。
